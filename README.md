# pdan8_bd_rentabilidad_cliente
El banco FinanPerú desea implementar un sistema que le permita analizar la rentabilidad generada por cada uno de sus clientes.  Actualmente, el banco dispone de información distribuida en diferentes sistemas: cuentas bancarias, tarjetas de crédito, préstamos, depósitos, operaciones realizadas por los clientes y cobros de comisiones.
